# Cursor AI Context: Photo Album Organizer

## Technology Stack

- Vite for build tooling and development server
- Vanilla HTML, CSS, and JavaScript (no frameworks)
- SQLite with sql.js for browser-based database
- File System Access API for local file operations
- Canvas API for image thumbnail generation
- HTML5 Drag and Drop API for album reordering
- History API for client-side routing
- Custom event system for state management


## Project Structure
- Single-page application with Vite
- Component-based vanilla JavaScript architecture
- SQLite database for local metadata storage
- File system access for photo management
- Responsive design with CSS Grid and Flexbox

## Key Implementation Notes
- Use minimal dependencies, prefer vanilla implementations
- Implement proper error handling and validation
- Follow accessibility guidelines (WCAG 2.1 AA)
- Optimize for performance with lazy loading and caching
- Use semantic HTML and proper ARIA labels

## Code Style Guidelines
- Use meaningful variable and function names
- Keep functions small and focused
- Add comments for complex logic
- Follow consistent naming conventions
- Use modern JavaScript features (ES2020+)

## Testing Requirements
- Unit tests for all business logic
- Integration tests for user flows
- Minimum 80% code coverage
- Test edge cases and error conditions
- Use descriptive test names

## Performance Targets
- Page load under 3 seconds
- Photo tiles load within 3 seconds
- Drag-and-drop operations under 2 seconds
- Optimize images and assets
- Implement lazy loading where appropriate
